# Техническое задание
## Информационная система грузоперевозок «ФураЕдет» (FuraEdet)

---

## 1. Общие сведения

| Параметр | Значение |
|----------|----------|
| Название | ФураЕдет (FuraEdet) |
| Тип | Веб-приложение (SaaS) |
| Назначение | Автоматизация логистики грузоперевозок |
| Целевая аудитория | Логистические компании, перевозчики, заказчики грузов |

### 1.1. Цели проекта

- Автоматизация расчёта стоимости перевозок
- Оптимизация распределения грузов по транспорту
- Управление автопарком и водителями
- AI-assisted планирование загрузки
- Маршрутизация с расчётом времени доставки

### 1.2. Ключевые преимущества

- Интеллектуальный помощник на базе Google Gemini
- Интеграция с Яндекс.Картами для маршрутизации
- Real-time трекинг грузов
- Визуализация загрузки транспорта

## 6. Функциональные требования

### 6.1. Гость (неавторизованный пользователь)

#### 6.1.1. Лендинг

- **Hero-секция**: Заголовок, подзаголовок, CTA "Рассчитать стоимость"
- **Преимущества**: 3-4 карточки с иконками
- **Автопарк**: Галерея/карусель транспорта
- **Как это работает**: 4 шага с нумерацией
- **Отзывы**: Карточки с рейтингом (звёзды)
- **CTA-секция**: Призыв к регистрации
- **Footer**: Контакты, ссылки, соцсети

#### 6.1.2. Калькулятор стоимости

**Входные данные:**
- Город отправления (autocomplete)
- Город назначения (autocomplete)
- Вес груза (кг)
- Объём груза (м³)

**Формула расчёта:**

```
Цена = (Расстояние_км × Тариф_за_км) + (Вес_кг × Коэффициент_веса)
```

**Выходные данные:**
- Предварительная стоимость
- Расстояние
- Примерное время доставки
- Кнопка "Оформить заявку" (→ регистрация/вход)

#### 6.1.3. Трекинг

- **Поле ввода**: Tracking ID (формат: FE-XXXXXX)
- **Результат**:
  - Статус заказа (с цветовой индикацией)
  - Маршрут (откуда → куда)
  - ETA (если в пути)
  - История статусов (timeline)

---

### 6.2. Клиент (авторизованный заказчик)

#### 6.2.1. Авторизация

- **Регистрация**: Email, пароль, имя, телефон
- **Вход**: Email + пароль
- **Имитация 2FA**: Код подтверждения на email (или фиксированный код для демо)
- **Восстановление пароля**: Email-ссылка

#### 6.2.2. Личный кабинет клиента

**Навигация (sidebar):**
- 📦 Новая заявка
- 📋 Мои заявки
- ⭐ Избранные адреса
- 👤 Профиль

**Подача заявки:**
1. Автозаполнение из калькулятора (если переход с лендинга)
2. Поля:
   - Адрес отправления (выбор из избранного или ввод)
   - Адрес доставки
   - Вес, объём
   - Описание груза
   - Дата желаемой отправки
3. Расчёт стоимости в реальном времени
4. Кнопка "Отправить заявку" → статус PENDING

**Список заявок:**
- Таблица с колонками: ID, Маршрут, Статус, Дата, Цена
- Поиск по: ID, городу, описанию
- Фильтры: Все / На рассмотрении / В работе / Доставлено / Отклонено
- Детальный просмотр заявки (модальное окно или отдельная страница)

**Избранные адреса:**
- CRUD адресов с названиями ("Склад", "Офис" и т.д.)
- Быстрый выбор при оформлении заявки

---

### 6.3. Менеджер (логист)

#### 6.3.1. Дашборд (главная)

**Статистика (карточки):**
- 💰 Выручка за месяц
- 📦 Заявок в работе
- 🚛 Свободных машин
- 👨‍✈️ Доступных водителей

**Графики:**
- Динамика заявок (линейный)
- Загруженность парка (круговой)

**Быстрые действия:**
- Новые заявки (бейдж с количеством)
- Машины без водителей (алерт)

#### 6.3.2. Управление заявками

**Список заявок:**
- Tabs: Новые / В работе / Отклонённые
- Таблица с действиями

**Действия над заявкой:**

| Действие | Описание |
|----------|----------|
| ✅ Принять | Перевод в статус IN_PROGRESS |
| ❌ Отклонить | Модальное окно с обязательным полем "Причина отклонения" |
| 📋 Детали | Просмотр полной информации |
| 🚛 Назначить транспорт | Выбор машины и водителя |

**Архив отклонённых:**
- Отдельная страница/вкладка
- Показывается причина отклонения

#### 6.3.3. Управление автопарком

**Список транспорта:**
- Карточки или таблица
- Визуальные статусы (цветовые бейджи)
- **Алерт**: Красная подсветка если `status = AVAILABLE` и `driver_id = NULL`

**CRUD операции:**
- ➕ Добавить машину
- ✏️ Редактировать
- 🗑️ Удалить (soft delete)

**Поля машины:**
- Госномер
- Марка, модель
- Грузоподъёмность (кг)
- Объём кузова (м³)
- Статус
- Привязанный водитель

#### 6.3.4. Управление водителями

**Типы водителей:**

| Тип | Подсветка | Дополнительные поля |
|-----|-----------|---------------------|
| Штатный | — | — |
| Наёмный | 🟡 Жёлтый | Госномер личного авто, Номер страховки (обязательные) |

**Валидация:**
- При выборе типа "Наёмный" → показать доп. поля
- Нельзя сохранить наёмного без госномера и страховки

**Блокировки:**
- Нельзя отправить фуру в рейс без назначенного водителя
- Визуальное предупреждение при попытке

#### 6.3.6. AI-ассистент

**Интеграция с Google Gemini:**

**Запрос:**

```json
{
  "trucks": [
    { "id": 1, "plate": "А123ВС", "capacity_kg": 5000, "capacity_m3": 20 }
  ],
  "orders": [
    { "id": 101, "weight": 500, "volume": 2, "destination": "Москва" },
    { "id": 102, "weight": 300, "volume": 1.5, "destination": "Москва" }
  ],
  "prompt": "Оптимально распредели грузы по машинам, учитывая направления"
}
```

**Ответ:**

```
Рекомендация:
- КамАЗ А123ВС: Загрузить заказы #101, #102 (общий вес 800 кг, направление Москва)
- Экономия: Объединение по направлению снизит стоимость на 15%
```

**UI:**
- Модальное окно или боковая панель
- История запросов
- Кнопка "Применить рекомендацию" (автозаполнение плана)

#### 6.3.7. Маршрутизация (Yandex Maps)

**Функционал:**
- Построение маршрута по нескольким точкам
- Визуализация на карте
- Расчёт расстояния и времени (из API)

**Расчёт ETA:**

```
ETA = Время_Яндекс + (Количество_точек × 3 часа на разгрузку)
```

**Интерфейс:**
- Интерактивная карта
- Список точек с возможностью сортировки
- Итоговые показатели: км, время, ETA

## 9. Нефункциональные требования

### 9.1. Производительность

- Время отклика API: < 500ms
- Время загрузки страницы: < 3 секунд
- Поддержка до 1000 одновременных пользователей

### 9.2. Безопасность

- JWT-аутентификация с refresh токенами
- HTTPS обязателен
- CORS настроен на домен фронтенда
- Rate limiting для API
- Валидация всех входных данных
- SQL-injection защита (Django ORM)

### 9.3. Совместимость

- Браузеры: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- Мобильные устройства: Responsive design (320px+)

### 9.4. Локализация

- Язык интерфейса: Русский
- Формат даты: DD.MM.YYYY
- Валюта: ₽ (RUB)
