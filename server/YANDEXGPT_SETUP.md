# 🇷🇺 Настройка YandexGPT (российский AI)

## ✅ Преимущества для предзащиты

- ✅ **Работает в России** без VPN
- ✅ **Бесплатный тариф** достаточен для демонстрации
- ✅ **Отлично понимает русский язык**
- ✅ **Российский сервис** (плюс для диплома)

---

## 🔑 Как получить API ключ

### Шаг 1: Регистрация в Yandex Cloud

1. Перейдите на https://cloud.yandex.ru/
2. Войдите через Яндекс аккаунт или зарегистрируйтесь
3. Создайте каталог (folder) - это будет ваш проект

### Шаг 2: Получение API-ключа

1. В Yandex Cloud перейдите в раздел **"Сервисные аккаунты"**
2. Создайте новый сервисный аккаунт
3. Назначьте роль: **"ai.languageModels.user"** (для YandexGPT)
4. Создайте API-ключ для этого аккаунта
5. **Скопируйте ключ** (он будет показан только один раз!)

### Шаг 3: Получение Folder ID

1. В Yandex Cloud откройте ваш каталог (folder)
2. В настройках каталога найдите **"ID каталога"**
3. **Скопируйте Folder ID** (выглядит как: `b1gxxxxxxxxxxxxxxxx`)

---

## ⚙️ Настройка в проекте

### Добавьте ключи в `.env.local`:

```env
YANDEXGPT_API_KEY=AQVNxxxxxxxxxxxxxxxxxxxxx
YANDEX_FOLDER_ID=b1gxxxxxxxxxxxxxxxx
```

**Важно:**
- Используйте `.env.local` (не `.env`) для безопасности
- Файл `.env.local` уже в `.gitignore` и не попадёт в репозиторий

---

## 🧪 Проверка работы

После добавления ключей перезапустите сервер:

```bash
cd server
python manage.py runserver
```

Система автоматически будет использовать YandexGPT как приоритетный AI сервис.
