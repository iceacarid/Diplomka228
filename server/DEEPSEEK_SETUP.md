# 🚀 Настройка DeepSeek AI (Бесплатно, без ограничений квоты)

## Что такое DeepSeek?

**DeepSeek** - это бесплатный AI сервис, который используется как альтернатива Gemini когда:
- Исчерпана квота Gemini
- Gemini недоступен
- Нужна работа без ограничений

## ✅ Преимущества

- 🆓 **Бесплатно** без ограничений квоты
- ⚡ **Автоматический fallback** - система сама переключится
- 🎯 **Качественные ответы** на русском языке
- 🔄 **OpenAI-совместимый API** - простая интеграция

## 📝 Как получить API ключ

1. Перейдите на https://platform.deepseek.com/api_keys
2. Войдите или зарегистрируйтесь (бесплатно)
3. Нажмите **"Create API Key"**
4. Скопируйте ключ (начинается с `sk-...`)

## ⚙️ Настройка

1. Откройте файл `server/.env.local` (или создайте его)

2. Добавьте строку:

```env
DEEPSEEK_API_KEY=sk-ваш_ключ_здесь
```

3. Перезапустите Django сервер:

```bash
cd server
.\venv\Scripts\Activate.ps1
python manage.py runserver
```

## 🔄 Как работает fallback?

Система автоматически пробует AI в таком порядке:

1. **Gemini** (если доступен и не исчерпана квота)
2. **DeepSeek** (если Gemini недоступен или квота исчерпана) ⭐
3. **Простой алгоритм** (если оба AI недоступны)

**Вы ничего не теряете!** Если Gemini работает - используется он. Если нет - автоматически DeepSeek.

## 🧪 Тестирование

После настройки ключа, попробуйте распределить заказы через AI. Если Gemini квота исчерпана, вы увидите:

```
🤖 Рекомендация от DeepSeek AI:
...
ℹ️ Использован DeepSeek AI (бесплатный, без ограничений квоты)
```

## 💡 Рекомендация

**Настройте оба ключа** для максимальной надёжности:
- `GEMINI_API_KEY` - основной (быстрый, качественный)
- `DEEPSEEK_API_KEY` - резервный (без ограничений)

Тогда система всегда будет работать, даже если один из сервисов недоступен!

## ❓ FAQ

**Q: Нужно ли платить за DeepSeek?**  
A: Нет, DeepSeek бесплатный без ограничений квоты.

**Q: Что если не настроить DeepSeek?**  
A: Система будет использовать простой алгоритм распределения (без AI).

**Q: Можно ли использовать только DeepSeek?**  
A: Да! Просто не настраивайте GEMINI_API_KEY, система будет использовать только DeepSeek.

**Q: Какой AI лучше?**  
A: Оба хороши! Gemini быстрее, DeepSeek без ограничений. Рекомендуем настроить оба.
