# 🚀 Настройка Groq AI (БЕСПЛАТНО, БЫСТРО, БЕЗ КВОТЫ!)

## ⭐ Почему Groq?

**Groq** - это ЛУЧШИЙ выбор для бесплатного AI:

- 🆓 **Полностью бесплатный** - без скрытых платежей
- ⚡ **Очень быстрый** - до 500 токенов в секунду!
- 🎯 **Щедрые лимиты**: 14,400 запросов в день
- 🚫 **Без ограничений квоты** - не нужно ждать
- 🌍 **Поддерживает русский язык**
- 🔧 **OpenAI-совместимый API** - легко интегрируется

## 📊 Лимиты Groq (бесплатно)

- ✅ **30 запросов в минуту**
- ✅ **14,400 запросов в день**
- ✅ **Без ограничений по токенам**
- ✅ **Множество моделей**: Llama 3.1, Mixtral, Gemma

## 📝 Как получить API ключ

1. Перейдите на https://console.groq.com/keys
2. Войдите через Google/GitHub (бесплатно)
3. Нажмите **"Create API Key"**
4. Скопируйте ключ (начинается с `gsk_...`)

## ⚙️ Настройка

1. Откройте файл `server/.env.local`

2. Добавьте строку:

```env
GROQ_API_KEY=gsk-ваш_ключ_здесь
```

3. Перезапустите Django сервер:

```bash
cd server
.\venv\Scripts\Activate.ps1
python manage.py runserver
```

## 🔄 Как работает fallback?

Система автоматически пробует AI в таком порядке:

1. **Gemini** (если доступен и не исчерпана квота)
2. **Groq** ⭐ (если Gemini недоступен) - **БЕСПЛАТНО, БЫСТРО!**
3. **DeepSeek** (если Groq недоступен)
4. **Простой алгоритм** (если все AI недоступны)

**Вы ничего не теряете!** Система автоматически выберет лучший доступный вариант.

## 💡 Рекомендация

**Настройте Groq как основной AI** - он самый быстрый и бесплатный!

Можно также настроить все три:
- `GROQ_API_KEY` - основной (быстрый, бесплатный)
- `GEMINI_API_KEY` - резервный
- `DEEPSEEK_API_KEY` - запасной

Тогда система всегда будет работать, даже если один из сервисов недоступен!
