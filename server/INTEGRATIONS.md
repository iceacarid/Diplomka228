# 🔌 Настройка внешних интеграций ФураЕдет

## Обзор

Система использует внешние API для расширенной функциональности:

1. **AI сервисы** (с автоматическим fallback):
   - **Google Gemini AI** - основной AI (бесплатно, но с квотой)
   - **DeepSeek AI** - альтернатива (бесплатно, без ограничений квоты)
   - **Простой алгоритм** - fallback если AI недоступны
2. **Yandex Maps API** - Геокодирование, маршрутизация, расчёт расстояний

---

## 🤖 Google Gemini API

### Зачем нужен?

- Интеллектуальная оптимизация распределения грузов по транспорту
- Учёт направлений доставки, грузоподъёмности, объёма
- Рекомендации по экономии топлива и рейсов

### Получение API ключа

1. Перейдите на https://makersuite.google.com/app/apikey
2. Войдите в аккаунт Google
3. Нажмите "Get API key" или "Create API key"
4. Скопируйте сгенерированный ключ

### Настройка

1. Создайте файл `.env` в папке `server/` (если его нет):

```bash
cd server
cp env.example .env
```

2. Откройте `.env` и добавьте ключ:

```env
GEMINI_API_KEY=ваш_ключ_здесь
```

3. Обновите зависимости (если требуется):

```bash
pip install -r requirements.txt
```

4. Перезапустите Django сервер:

```bash
python manage.py runserver
```

### Тестирование

```bash
python test_integrations.py
```

Должно появиться:

```
✅ ТЕСТ ПРОЙДЕН: Gemini API работает корректно!
```

### Лимиты бесплатного тарифа

- **15 запросов в минуту**
- **1500 запросов в день**

⚠️ **Важно:** При исчерпании квоты система автоматически переключится на DeepSeek (если настроен) или простой алгоритм.

💡 **Рекомендация:** Настройте также DEEPSEEK_API_KEY для бесперебойной работы без ограничений квоты!

### Что будет без ключа?

Система автоматически попробует использовать **DeepSeek AI** (если настроен), или **простой алгоритм** распределения.

---

## 🚀 DeepSeek AI API (Альтернатива Gemini)

### Зачем нужен?

- **Бесплатный** без ограничений квоты (в отличие от Gemini)
- Автоматически используется если Gemini недоступен или квота исчерпана
- Такой же качественный AI для оптимизации распределения грузов

### Получение API ключа

1. Перейдите на https://platform.deepseek.com/api_keys
2. Войдите или зарегистрируйтесь (бесплатно)
3. Нажмите **"Create API Key"**
4. Скопируйте сгенерированный ключ

### Настройка

Добавьте в `.env.local` файл:

```env
DEEPSEEK_API_KEY=ваш_ключ_deepseek_здесь
```

### Преимущества DeepSeek

- ✅ **Бесплатно** без ограничений квоты
- ✅ **Автоматический fallback** если Gemini недоступен
- ✅ **OpenAI-совместимый API** (простая интеграция)
- ✅ **Качественные ответы** на русском языке

### Как работает fallback?

Система пробует AI в следующем порядке:

1. **Gemini** (если доступен и не исчерпана квота)
2. **DeepSeek** (если Gemini недоступен или квота исчерпана)
3. **Простой алгоритм** (если оба AI недоступны)

**Рекомендация:** Настройте оба ключа для максимальной надёжности!

## 🗺️ Yandex Maps API

### Зачем нужен?

- Геокодирование адресов (получение координат)
- Расчёт расстояния между точками
- Построение маршрутов с учётом дорожной ситуации
- Расчёт ETA (времени доставки)

### Получение API ключа

1. Перейдите на https://developer.tech.yandex.ru/
2. Войдите или зарегистрируйтесь
3. Перейдите в раздел **"JavaScript API и HTTP Геокодер"**
4. Нажмите **"Получить ключ"** или **"Подключить API"**
5. Включите:
   - ✅ **Geocoder API** (геокодирование)
   - ✅ **Router API** (маршрутизация)
6. Скопируйте API ключ

### Настройка

Добавьте в `.env` файл:

```env
YANDEX_MAPS_API_KEY=ваш_ключ_yandex_здесь
```

### Тестирование

```bash
python test_integrations.py
```

Должно появиться:

```
✅ Адрес: Москва, Красная площадь
   Координаты: 55.7539, 37.6208
✅ Маршрут: Москва → Санкт-Петербург
   Расстояние: 712.3 км
```

### Лимиты бесплатного тарифа

Yandex предоставляет **25 000 запросов в день** бесплатно для:
- Geocoder API
- Router API (с ограничениями)

### Что будет без ключа?

Система будет использовать **fallback-значения**:

- Расстояние: `500 км` (примерное)
- Время в пути: `8 часов` (примерное)
- Координаты Москвы по умолчанию: `55.751244, 37.618423`

**Калькулятор стоимости продолжит работать!**

## ❌ Решение проблем

### Ошибка: "API_KEY_INVALID"

**Причина:** Неверный или устаревший API ключ

**Решение:**
1. Проверьте, что ключ скопирован полностью (без пробелов)
2. Сгенерируйте новый ключ
3. Убедитесь, что в .env нет кавычек вокруг ключа

### Ошибка: "RESOURCE_EXHAUSTED" (Gemini)

**Причина:** Превышен лимит запросов (60/мин или 1500/день)

**Решение:**
1. Подождите 1 минуту
2. Используйте кэширование результатов
3. Ограничьте количество запросов от пользователей

### Ошибка: "403 Forbidden" (Yandex)

**Причина:** API ключ не активирован или превышен лимит

**Решение:**
1. Проверьте статус ключа на https://developer.tech.yandex.ru/
2. Убедитесь, что включены Geocoder и Router API
3. Проверьте лимиты использования

### .env файл не читается

**Причина:** Файл не в корне папки server/

**Решение:**
```bash
# Убедитесь, что файл находится здесь:
server/.env

# А НЕ здесь:
.env
FuraEdet_Diploma/.env
```

### Модуль google.generativeai не найден

**Причина:** Не установлены зависимости

**Решение:**
```bash
cd server
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## 🔒 Безопасность

### ⚠️ ВАЖНО:

1. **НЕ** коммитьте `.env` файл в Git (уже в .gitignore)
2. **НЕ** показывайте API ключи в коде или скриншотах
3. **НЕ** используйте production ключи для разработки
4. **НЕ** публикуйте ключи в открытом доступе

### Для production:

- Используйте переменные окружения сервера
- Ограничьте домены для API ключей
- Включите rate limiting
- Мониторьте использование API
