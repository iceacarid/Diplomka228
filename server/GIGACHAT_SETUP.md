# 🇷🇺 Настройка GigaChat (Сбер, российский AI)

## ✅ Преимущества для предзащиты

- ✅ **Работает в России** без VPN
- ✅ **Бесплатный тариф** для разработчиков
- ✅ **Отлично понимает русский язык**
- ✅ **Российский сервис** (Сбер, плюс для диплома)

---

## 🔑 Как получить API ключ

### Шаг 1: Регистрация

1. Перейдите на https://developers.sber.ru/
2. Зарегистрируйтесь или войдите через аккаунт Сбер ID

### Шаг 2: Создание приложения

1. В личном кабинете перейдите в раздел **"GigaChat"**
2. Создайте новое приложение
3. Заполните данные приложения (название, описание)
4. После создания приложения получите **API-ключ**

### Шаг 3: Копирование ключа

1. В настройках приложения найдите **"API-ключ"**
2. **Скопируйте ключ** (сохраните его безопасно!)

---

## ⚙️ Настройка в проекте

### Добавьте ключ в `.env.local`:

```env
GIGACHAT_API_KEY=ваш_ключ_gigachat_здесь
```

**Важно:**
- Используйте `.env.local` (не `.env`) для безопасности
- Файл `.env.local` уже в `.gitignore` и не попадёт в репозиторий

---

## 🧪 Проверка работы

После добавления ключа перезапустите сервер:

```bash
cd server
python manage.py runserver
```

Система автоматически будет использовать GigaChat как резервный AI сервис (после YandexGPT).
