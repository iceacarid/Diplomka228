СДЕЛАНО:
  Система обновлена! Ключи читаются из .env.local с приоритетом

ПОРЯДОК ЗАГРУЗКИ:
  1. .env.local   <- ПРИОРИТЕТ (ваши секретные ключи)
  2. .env         <- Резервный (общие настройки)
  3. Системные    <- Windows переменные окружения


ЧТО ДЕЛАТЬ СЕЙЧАС:

  Шаг 1: Создайте .env.local
  --------------------------------
  
    cd E:\FuraEdet_Diploma\server
    copy .env.local.example .env.local


  Шаг 2: Откройте в Notepad (НЕ в чате с AI!)
  --------------------------------
  
    notepad .env.local


  Шаг 3: Вставьте ВАШИ настоящие ключи
  --------------------------------
  
    GEMINI_API_KEY=ваш_новый_ключ_gemini
    YANDEX_MAPS_API_KEY=319fa1e7-820a-4888-9dd0-66c052888d31
    
    (БЕЗ кавычек!)


  Шаг 4: Сохраните и закройте
  --------------------------------
  
    Файл -> Сохранить
    НЕ копируйте содержимое в чат!


  Шаг 5: Проверьте работу
  --------------------------------
  
    python manage.py runserver
    
    В консоли должно быть:
    "Загружены настройки из .env.local"


БЕЗОПАСНОСТЬ:

  ВАШ .env.local:
    НЕ в Git
    AI НЕ видит
    Только на вашем компьютере
    Не распространяется на другие проекты


ДЛЯ ДРУГИХ ПРОЕКТОВ:

  Создайте ОТДЕЛЬНЫЙ .env.local в каждом проекте
  
  ФураЕдет/server/.env.local        <- Ключи ФураЕдет
  ДругойПроект/backend/.env.local   <- Другие ключи
