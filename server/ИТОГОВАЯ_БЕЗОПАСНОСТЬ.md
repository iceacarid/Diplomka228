## 🎯 Ответы на ваши вопросы:

### 1. Ключ берётся из .env.local или .env?

**Ответ:** Из **`.env.local`** с **ПРИОРИТЕТОМ**! 
- Если `.env.local` существует → берёт ключи оттуда
- Если `.env.local` НЕТ → берёт из `.env`

### 2. Как сделать чтобы AI не видел ключи?

**Ответ:** Храните в `.env.local` и **НЕ открывайте** этот файл в IDE когда работаете с AI!

**Правила:**
- ✅ Редактируйте `.env.local` в Notepad (отдельное окно)
- ✅ НЕ открывайте `.env.local` в VS Code / Cursor
- ✅ НЕ показывайте скриншоты с ключами
- ✅ НЕ копируйте содержимое в чат

### 3. Ключи не распространяются на другие проекты?

**Ответ:** НЕТ! Каждый проект - свой `.env.local`:

```
Диск E:\
├── ФураЕдет\server\.env.local      ← Ключи только для ФураЕдет
├── ДругойПроект\backend\.env.local ← Другие ключи
└── ТретийПроект\.env.local         ← Третьи ключи
```

**Ключи изолированы по папкам!**
