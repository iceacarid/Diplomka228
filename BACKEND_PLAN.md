# План разработки Backend (по частям)

## 🎯 Общая структура

### Этап 1: Базовая настройка Django
- Создание проекта Django
- Настройка PostgreSQL
- Базовая структура приложений

### Этап 2: Система аутентификации
- Модель пользователя (кастомная)
- Регистрация (API endpoint)
- Авторизация (API endpoint)
- JWT токены или Session-based auth

### Этап 3: Защита и валидация
- Middleware для проверки токенов
- Валидация данных
- Обработка ошибок

### Этап 4: Профиль пользователя
- Получение профиля
- Обновление профиля
- Смена пароля

---

## 📋 Последовательность разработки

1. **Настройка Django проекта** → Промпт 1
2. **Модель User** → Промпт 2
3. **API регистрации** → Промпт 3
4. **API авторизации** → Промпт 4
5. **HTML страницы (регистрация/авторизация)** → Промпт 5
6. **Главная страница (после авторизации)** → Промпт 6

---

## 🔧 Технологии

- Django 6.0+
- Django Rest Framework
- PostgreSQL
- JWT токены (djangorestframework-simplejwt)
- HTML/CSS/JavaScript (чистый, без фреймворков)

---

## 📁 Структура проекта

```
server/
├── core/              # Настройки Django
├── users/             # Приложение пользователей
│   ├── models.py      # Модель User
│   ├── views.py       # API endpoints
│   ├── serializers.py # DRF сериализаторы
│   └── urls.py        # URL маршруты
├── templates/         # HTML шаблоны
│   ├── auth/
│   │   ├── register.html
│   │   └── login.html
│   └── dashboard/
│       └── index.html
└── static/           # CSS, JS, изображения
```
