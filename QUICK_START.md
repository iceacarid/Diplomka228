## 🚀 Начало работы

1. **Открой файл `CURSOR_PROMPTS.md`**
2. **Скопируй ПРОМПТ 1** в Cursor
3. **Выполни промпт** и проверь результат
4. **Переходи к следующему промпту** только после успешного выполнения предыдущего

## ⚠️ Частые проблемы

1. **Ошибка подключения к БД** - проверь настройки PostgreSQL в settings.py
2. **CORS ошибки** - убедись, что django-cors-headers настроен правильно
3. **Токены не работают** - проверь настройки SIMPLE_JWT
4. **Шаблоны не находятся** - проверь путь к templates в settings.py

## 📚 Полезные команды

```bash
# Создание миграций
python manage.py makemigrations

# Применение миграций
python manage.py migrate

# Создание суперпользователя
python manage.py createsuperuser

# Запуск сервера
python manage.py runserver

# Проверка проекта
python manage.py check
```
