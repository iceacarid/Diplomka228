# ФураЕдет - Система управления грузоперевозками

Информационная система для автоматизации процессов расчета стоимости, распределения грузов и управления автопарком с использованием искусственного интеллекта.

## 🚀 Проект готов к разработке

Проект инициализирован и готов к началу разработки.

## 📋 План разработки

### Этап 1: Backend (Django)
- Настройка Django проекта
- Создание моделей данных
- Настройка PostgreSQL
- API endpoints (DRF)

### Этап 2: Frontend (React)
- Настройка React + Vite
- Интеграция с backend API
- UI компоненты

## 🛠️ Технологический стек

### Backend (планируется)
- Python 3.14+
- Django 6.0+
- Django Rest Framework
- PostgreSQL

### Frontend (планируется)
- React + Vite + TypeScript
- Tailwind CSS
- Yandex Maps API
